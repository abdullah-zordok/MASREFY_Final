# US4 — Private support workflows

Customer and Admin contract/security/integration coverage verifies ordered active
categories, owner-only tickets and messages, assignment/priority/reply/resolve/close/
reopen transitions, optimistic versions, idempotency, stable cursors, safe errors,
exact permissions, recent MFA, atomic audit/outbox, and safe invalidation IDs. Sender,
status, assignee, priority, and internal-note fields cannot be customer-controlled.
