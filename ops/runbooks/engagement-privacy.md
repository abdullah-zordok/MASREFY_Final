# Engagement privacy incidents

## Internal-note exposure

Disable the affected customer route or export worker, preserve audit IDs, and verify the private note table has no client grant/publication. Search response schemas, logs, caches, exports, and signed-download paths for note fields or existence metadata. Rotate credentials only if secret exposure is independently confirmed.

## Draft-content exposure

Invalidate the in-process content cache, retire the affected item through the guarded action, and confirm customer RLS/search returns published rows only. Realtime/outbox messages may contain only content IDs and lifecycle event names, never draft text.
